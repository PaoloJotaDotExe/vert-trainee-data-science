# Mental Health in Brazil: Exploratory Data Analysis

**Notebook:** [`mental_health_eda.ipynb`](mental_health_eda.ipynb)

## Problem
Analyze the prevalence of five mental disorders in Brazil over time and compare it with Latin America and the world.

## Data
[Our World in Data: mental illness prevalence](https://ourworldindata.org/mental-health).

## Approach
- Loaded the data into SQLite and answered the questions with SQL queries.
- Time-series and comparative charts with matplotlib and seaborn.

## Result
An exploratory report answering each question with SQL and charts.
