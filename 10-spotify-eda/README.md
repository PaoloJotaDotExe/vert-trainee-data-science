# Spotify Tracks: Exploratory Data Analysis

**Notebook:** [`spotify_eda.ipynb`](spotify_eda.ipynb)

## Problem
Explore what characterizes popular tracks and how music changed over the decades.

## Data
Spotify tracks dataset from Kaggle (`train.csv`, with a data dictionary). Not redistributed here.

## Approach
- Popularity distribution and top tracks.
- Number of tracks and explicit content by decade.
- Feature relationships, plus a first Random Forest regressor for popularity.

## Result
A visual, exploratory study. The regressor is a starting point, not a validated model.
