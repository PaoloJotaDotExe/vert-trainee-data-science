# Extras

Smaller exercises from the program.

| Notebook | What it does |
|---|---|
| [`monty_hall.ipynb`](monty_hall.ipynb) | Simulates the Monty Hall problem many times to show empirically that switching doors wins about 2/3 of the time. |
| [`zipf_law.ipynb`](zipf_law.ipynb) | Checks Zipf's law (word frequency ∝ 1/rank) on the full text of the Portuguese Bible. |
| [`airports_and_routes.ipynb`](airports_and_routes.ipynb) | Merges airport and flight-route datasets and computes the distance between cities for each route. |
