# Titanic Survival Prediction

**Notebook:** [`titanic.ipynb`](titanic.ipynb)

## Problem
Predict passenger survival on the Titanic.

## Data
[Titanic dataset](https://www.kaggle.com/datasets/yasserh/titanic-dataset) (Kaggle).

## Approach
- Exploratory analysis of survival by class, sex, and age.
- Missing-value treatment and categorical encoding.
- Random Forest classifier with a classification report.

## Result
**81% accuracy** (0.78 macro-F1).
